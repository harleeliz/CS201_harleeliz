# CS201: Accelerated Introduction to Computer Science – Fall 2023

This repository contains all my coursework, programming labs, and assignments for **CS201: Accelerated Introduction to Computer Science**, offered at **Illinois Institute of Technology** during **Fall 2023**.

This course offers a fast-paced introduction to fundamental programming concepts and problem-solving using **Java**. Through both theoretical and hands-on practice, students develop skills in structured programming, algorithm development, and basic object-oriented principles.

## Key Concepts Covered

This course builds foundational programming skills and computational thinking. Topics covered include:

- **Basic Programming Constructs**  
  Assignment, conditionals, loops, input/output (including file I/O), and methods

- **Object-Oriented Concepts**  
  Encapsulation, information hiding, modular design, class-based structures

- **Algorithm Design**  
  Problem decomposition, pseudocode, iterative development, testing/debugging

- **Data Structures**  
  Strings, arrays, and their memory representation

- **Algorithm Analysis**  
  Time complexity estimation, Big-O analysis of simple algorithms

- **Search & Sort Algorithms**  
  Sequential search, binary search, selection sort, insertion sort

- **Recursion**  
  Recursive function design, base cases, and debugging

- **APIs and Java Libraries**  
  Using `java.util`, `java.io`, and custom method libraries

## Sample Topics and Weekly Labs

- Week 1–2: Java syntax, variables, conditionals, I/O  
- Week 3–4: Loops, nested logic, method declarations  
- Week 5: Arrays and memory layout  
- Week 6–7: Writing reusable functions and working with strings  
- Week 8: Midterm exam preparation  
- Week 9–10: Object-oriented introduction (classes & objects)  
- Week 11–12: Sorting algorithms: selection, insertion  
- Week 13: Searching algorithms: sequential and binary search  
- Week 14: Introduction to recursion  
- Week 15–16: Final exam review and project presentations
